# Conocimiento de GEO Engine

`templates/` contiene plantillas iniciales para productos/servicios y registro de
evidencias, adaptadas nominalmente del workspace de origen.
El runtime importa JSON/CSV mediante `geo_engine.catalog` y conocimiento Markdown
de empresas mediante `geo_engine.company_knowledge`. Las plantillas se completan
en la carpeta empresarial antes de importar. No guardar información real de clientes aquí.
