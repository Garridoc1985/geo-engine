## Notes

- Evidence IDs must never be reused (RFC-010 §4).
- Lifecycle: Captured → Registered → Reviewed → Validated → Referenced → Archived (RFC-010 §6).
- This registry does not replace `discovery_observation_log.md` — the Observation Log captures raw meeting evidence; this registry assigns it a permanent, traceable identifier once reviewed.
- This is a manual template (no automation, no ID generator) — assign the next sequential `EV-00000X` by hand.
